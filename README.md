# 🎓 تطبيق تعلم الإنجليزية | Learn English App

تطبيق ويب تكيّفي لتعلم اللغة الإنجليزية مبني بـ **Next.js + SQLite**.

---

## 🚀 تشغيل التطبيق

```bash
cd "C:\Users\Hamza\Desktop\learn-eng-app"
npm run dev
```

ثم افتح المتصفح على: **http://localhost:3000**

---

## ✨ الميزات الرئيسية

| الميزة | الوصف |
|--------|-------|
| 🧠 اختبار تحديد المستوى | يحدد مستواك تلقائياً (A1→C2) |
| 👁️ → 📖 → 🔊 → ✍️ → 🧪 | دورة التعلم الخماسية لكل كلمة |
| 🔄 Spaced Repetition | خوارزمية SM-2 لمراجعة ذكية |
| 📦 بنك المفردات | كلماتك مع نسبة أدائك في كل كلمة |
| 🔥 Streak + ⭐ XP | نظام تحفيز يومي |

---

## ➕ إضافة كلمات جديدة

افتح `src/data/words.json` وأضف كلمات ضمن المستوى المناسب.

---

## 🗄️ قاعدة البيانات

ملف SQLite محلي في: `data/learn-eng.db` — قابل للترقية للسحابة لاحقاً.
